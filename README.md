# 📊 経済ニュース ダッシュボード

日本・世界の主要経済ニュースをまとめる、自分専用のニュースサイトです。
**マクロ経済・金融政策 / 市場・株・為替 / 国際・地政学** の3本柱で毎朝自動更新されます。

## 構成

```
.
├── index.html            # ダッシュボード本体
├── assets/
│   ├── style.css         # スタイル（ライト/ダーク両対応）
│   └── app.js            # 描画ロジック
├── data/
│   └── news.js           # ニュースデータ（毎朝自動で書き換わる）
├── .github/workflows/
│   └── pages.yml         # GitHub Pages への自動デプロイ
└── UPDATE.md             # 自動更新セッションへの指示書
```

データ（`data/news.js`）とサイト本体を分離しているので、
毎朝の更新はデータファイルの書き換えだけで完結します。

## 見る方法

### A. GitHub Pages で公開する（おすすめ）

1. このブランチを `main` にマージ（またはPagesの対象ブランチに設定）
2. リポジトリの **Settings → Pages** で **Source: "GitHub Actions"** を選択
3. `main` に push されるたびに自動でデプロイされ、公開URLが発行されます

### B. ローカルで見る

`data/news.js` はグローバル変数として読み込むため、
ファイルを直接ブラウザで開くだけでも表示できます。

```
# もしくは簡易サーバー経由で
python3 -m http.server 8000
# → http://localhost:8000
```

## 自動更新の仕組み

毎朝スケジュール実行される Claude セッションが `UPDATE.md` の手順に従って:

1. 3カテゴリの最新ニュースをWeb検索で収集
2. 相場サマリーを更新
3. `data/news.js` を書き換え
4. コミットして push（→ GitHub Pages が自動で再デプロイ）

を自動で行います。手順を変えたいときは `UPDATE.md` を編集してください。

## カスタマイズ

- **カテゴリを増やす**: `data/news.js` の `categories` に項目を追加
- **色・レイアウト**: `assets/style.css` の `:root` 変数を編集
- **相場銘柄**: `data/news.js` の `market_snapshot` を編集
